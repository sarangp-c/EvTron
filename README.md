# EvTron

A zero-friction campus event discovery platform. EvTron uses a Telegram bot to automatically parse event posters using multimodal AI and pushes them to a live Next.js feed.

## Development Checkpoints
- [x] **Phase 1:** Supabase Database Schema & RLS configured.
- [x] **Phase 2a & 2b:** Telegram bot initialized and basic Echo functionality working.
- [ ] **Phase 2c:** Bot can receive and download photo payloads.
- [ ] **Phase 2d:** Gemini AI extracts JSON metadata from posters.
- [ ] **Phase 2e:** Bot pushes validated data to Supabase database.
